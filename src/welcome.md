# 欢迎使用 Typero

一个安静、克制的本地 Markdown 阅读与写作空间。打开一份文稿，或者从这句话开始你的记录。

> 好的阅读器应该退到文字身后：没有多余的工具栏，没有打扰，只留下清晰的字句和恰到好处的留白。

## 三种阅读方式

Typero 提供了三种视图，随时切换，不必离开当前文稿。

| 模式 | 适合做什么 | 快捷键 |
| :--- | :--- | :--- |
| **阅读** | 沉浸阅读，专注排版后的内容 | `Alt` + `1` |
| **分栏** | 左右对照，边写边看渲染效果 | `Alt` + `2` |
| **源码** | 只面对 Markdown 文本，心无旁骛 | `Alt` + `3` |

在分栏模式下拖动中间的分隔线，可以自由调整两栏宽度；左右两侧的滚动位置也会保持同步。

## 已经为你准备

- [x] 明暗两套主题，跟随系统或手动切换
- [x] 标题大纲，点击即可跳转
- [x] 代码高亮、表格、任务列表与数学公式
- [ ] 打开你自己的 `.md` 文件，开始真正的阅读

字体、行距和对比度都经过调整，适合长时间阅读。点击右上角的太阳或月亮图标，可以在暖白纸张与深色墨夜之间切换。

## 一些 Markdown

行内代码写作 `const idea = "slow down";`，强调可以**加粗**、*倾斜*或~~删除~~。

```js
// 文字是安静的，工具也应该如此。
const typero = {
  theme: "dark",
  local: true,
  distractions: 0,
  open(markdown) {
    return render(markdown);
  }
};
```

数学公式同样可以被优雅地呈现：$e^{i\pi} + 1 = 0$。

$$
\int_{0}^{\infty} \frac{x^{3}}{e^{x} - 1}\,dx = \frac{\pi^{4}}{15}
$$

## 文稿只属于你

Typero 在本机运行，不连接服务器，也不会上传、分析或同步你的文字。你的 Markdown 文件保留在原来的位置，编辑后的内容由你亲自保存。

现在，打开一份文稿，或者删除这些示例，写下你自己的第一行。
