# Typero

一个安静、克制的本地 Markdown 阅读器与编辑器，带 **深色 / 浅色** 两套主题。  
所有文稿只在本机处理，不上传、不同步。

## 启
双击 `start.cmd` 即可。

首次运行会自动安装依赖并构建页面，然后在后台启动 Typero 本地服务，并以独立的 Edge / Chrome 应用窗口打开界面。  
如果电脑上没有 Edge 或 Chrome，会在默认浏览器中打开。

也可以手动运行：

```powershell
npm install
npm run build
npm start
```

本地服务只监听 `127.0.0.1`，可同时服务多个 Typero 窗口。  
需要完全停止服务时，运行 `stop-typero.cmd`（停止前请先关闭所有 Typero 窗口）。

## 双击打开 Markdown

运行一次 `install-typero-association.cmd`，即可把 `.md`、`.markdown`、`.mdown`、`.mkd` 关联到 Typero。

之后在资源管理器中双击任意 Markdown 文件，Typero 会自动打开它；编辑后按 `Ctrl + S` 会直接写回原文件。可以同时打开多个文稿窗口。

- 如果系统此前已经为 `.md` 指定了其他默认程序，Windows 可能仍使用旧程序。请到“设置 → 应用 → 默认应用”中把对应扩展名设为 Typero，或右键文件选择“打开方式 → Typero”。
- 移除关联：运行 `uninstall-typero-association.cmd`。
- 文件关联通过当前 Windows 用户的注册表配置完成，不需要管理员权限。
- 如果移动了 Typero 项目目录，需要重新运行一次关联安装脚本。

## 功能

- **阅读 / 分栏 / 源码** 三种视图，随时切换
- 深色、浅色主题，记忆你的选择；首次启动可跟随系统偏好
- 打开、编辑并**原地保存**本地 `.md` 文件（基于 File System Access API 或本地服务）
- 双击 `.md` 文件直接用 Typero 打开，并支持原地保存
- 自动备份未保存的草稿，下次打开自动恢复
- 标题大纲，支持点击跳转与阅读位置跟随
- 分栏滚动同步，拖动分隔线调整两栏比例（双击复位）
- 代码语法高亮与一键复制
- 表格、任务列表（可直接勾选并同步回 Markdown）、图片、KaTeX 数学公式
- 字数、字符、段落、预计阅读时间统计
- 专注阅读模式（F8），隐藏所有界面元素
- 导出独立 HTML、打印 / 导出 PDF
- 拖放 Markdown 文件到窗口中打开

## 快捷键

| 操作 | 快捷键 |
| :--- | :--- |
| 打开文件 | `Ctrl + O` |
| 保存 | `Ctrl + S` |
| 另存为 | `Ctrl + Shift + S` |
| 新建文稿 | `Ctrl + N` |
| 阅读 / 分栏 / 源码 | `Alt + 1` / `Alt + 2` / `Alt + 3` |
| 显示或收起侧栏 | `Ctrl + \` |
| 加粗 / 斜体 | `Ctrl + B` / `Ctrl + I` |
| 行内代码 / 链接 | ``Ctrl + ` `` / `Ctrl + K` |
| 专注阅读 | `F8` |
| 退出专注 / 关闭菜单 | `Esc` |

编辑器内按 `Tab` 插入缩进，列表项末尾按 `Enter` 自动续写。

## 主题

点击右上角的太阳 / 月亮按钮切换。首次启动时跟随系统的深浅色偏好，之后会记住手动选择。

## 文件与隐私

- Typero 只在本机运行，页面与本地服务仅绑定 `127.0.0.1`。
- 文字内容不会上传，也没有任何分析、遥测或云同步。
- 打开文件后，编辑不会自动写回磁盘；请按 `Ctrl + S` 或点击“保存”。
- 通过双击关联打开的文稿会使用一个随机的本地会话令牌读取和保存原文件，不会把文件路径暴露给公网。
- 编辑过程中会把草稿保存在浏览器本地存储中，以防意外关闭丢失；关联窗口使用独立会话草稿，避免多个窗口互相覆盖。
- 文稿中如果嵌入了**远程图片**，浏览器会直接向图片所在服务器发起请求；不包含远程资源时完全离线可用。

## 已知限制

- 手动“打开文件”时，Chromium 内核浏览器（Edge / Chrome）可获得原地保存与系统文件选择器；其他浏览器会退化为“打开文件 + 下载副本”。双击关联打开的文稿使用本地服务保存，不受此限制。
- 文稿内使用相对路径引用的本地图片无法自动读取（浏览器安全限制）。绝对 URL、`data:` 图片可用。
- 目前以阅读和编辑 Markdown 文本为主，不包含文件夹树、多标签、协同编辑等功能。

## 开发

```text
src/
  index.html      界面结构
  styles.css      主题与排版
  app.js          编辑、渲染与文件操作
  welcome.md      首次启动的示例文稿
scripts/build.mjs        esbuild 构建脚本
scripts/launch.mjs       启动并复用本地后台服务
scripts/open-with-typero.vbs  文件关联使用的静默启动器
scripts/install-association.ps1  注册 / 移除 Windows 文件关联
server.mjs               本地静态服务器、文件读写 API 与应用窗口启动
assets/typero.ico        文件关联图标
dist/                    构建产物
.typero/                 运行时凭据、日志与关联备份（自动生成）
```

修改 `src/` 后运行 `npm run build`，或直接重新执行 `start.cmd`（会自动构建）。

项目内附带基于系统 Edge 的端到端测试（需要 Edge 与 Playwright 依赖）：

```powershell
npm test
```

它会覆盖深浅主题、三种视图、任务勾选同步、保存、导出、草稿恢复、标题大纲、移动端布局，以及文件关联的启动、原地保存与会话草稿恢复。
